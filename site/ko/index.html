Slack에서 묻고,
터미널에서 이어가세요.

Pacenote는 무료 Mac 앱이에요. Slack에서 어시스턴트 Pace를 멘션하면 내 Claude Code나 Codex 로그인으로 답하고, 할 일마다 그간의 기록을 챙겨 실제로 작업할 터미널 세션에 넘겨줘요.

brew install --cask ashon/tap/pacenote
작동 방식

무료 오픈 소스예요. Apple silicon Mac, 내 Claude나 ChatGPT 요금제, 그리고 앱을 만들 수 있는 Slack 워크스페이스가 필요해요. 텔레메트리는 없어요.

모든 도구가 Pacenote에 결과를 알려요

부탁은 Slack 스레드로 들어오고, 작업은 Claude Code, Codex, opencode에서 하고, 각 도구는 어떻게 끝났는지 Pacenote에 알려요. 이 모든 게 내 Mac에, 또는 두 Mac 모두에 하나의 기록으로 남아서, 다음 할 일은 어느 도구에서든, 어느 Mac에서든 앞서 있었던 일을 알고 시작해요.

Pace는 스레드에서 답해요

Slack 스레드에서 @Pace를 멘션하세요. 스레드와 파일을 읽고, 로그인해 둔 claude나 codex CLI로 답을 찾아 바로 그 자리에서 답해요. 거친 단계는 모두 남겨 둬요.

답변이 만들어지는 과정

멈춘 곳에서 이어가세요

지금 모으기를 누르면 사람들이 Slack에서 내게 부탁한 일이 목록으로 정리돼요. Claude Code에서 계속이나 Codex, opencode에서 계속을 누르면, 스레드와 Pace가 찾은 내용, 지난번 관련 작업이 어떻게 끝났는지를 이미 담은 세션이 열려요.

할 일과 넘겨주기

다른 Mac에서 이어가세요

두 Mac에 Pacenote가 있으면 할 일과 각 할 일의 진행 상황이 두 Mac에서 같고, Pace는 지금 쓰는 Mac에서 답해요. 그 Mac을 잠그거나, 뚜껑을 닫거나, 자리를 비우면 Pace가 다른 Mac으로 옮겨가요. 두 Mac은 중간에 서버 없이 내 네트워크에서 서로를 찾아요.

Mac 사이에서 넘겨받는 방식

마무리는 내가 보내는 답장으로

작업이 끝나면 할 일은 어떻게 끝났는지 메모를 남기고 닫혀요. 누군가 기다리고 있다면 스레드에 붙여 넣을 답장 초안을 받아요. Pace가 대신 보내는 일은 없어요.

할 일이 닫히는 방식

Pace가 절대 하지 않는 일

  • 나 말고 다른 사람에게 답하기
  • 비공개 채널이나 DM에서 답하기
  • 나 대신 메시지 보내기
  • 내 파일 바꾸기
  • 내 자격 증명을 모델에 넘기기
  • 공개 엔드포인트를 열거나 몰래 외부로 정보 보내기
  • 요금 청구하기
이유와 하나하나 확인하는 방법

Pacenote 설치하기

brew install --cask ashon/tap/pacenote

함께 다듬어 보고 싶다면 디자인 파트너로 참여해 주세요. 한 달 동안 써 보시고, 2주마다 무엇이 좋고 불편했는지 들려주시면 돼요.
