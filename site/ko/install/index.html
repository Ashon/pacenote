Pacenote 설치하기

Homebrew 명령 하나면 되고, 앱 안의 초기 설정은 Slack에서 Pace가 답하면 끝나요.

brew install --cask ashon/tap/pacenote

필요한 것

  • macOS 12 이상의 Apple silicon Mac. 내장 샌드박스에는 macOS 15가 필요해요.
  • Claude Pro, Max, Team, Enterprise 요금제의 Claude Code, 또는 ChatGPT Plus, Pro, Business의 Codex 0.138 이상. 그 Mac에서 로그인되어 있어야 해요.
  • 앱을 만들 수 있는 Slack 워크스페이스, 또는 팀의 Pacenote 허브.
  • 할 일 모으기에는: claude.ai 계정의 Slack 커넥터를 연결한 Claude Code, 또는 ChatGPT의 Slack 앱을 연결한 Codex.

초기 설정은 Pace의 첫 답변으로 끝나요

  1. Homebrew로 설치하세요: brew install --cask ashon/tap/pacenote
  2. Pacenote를 여세요. 초기 설정이 AI 서비스, 답변을 실행할 곳, Slack, 마지막 확인까지 차례로 안내해요. 어느 단계에서든 멈췄다가 나중에 개요에서 이어서 할 수 있어요.
  3. 스레드에서 @Pace를 멘션하세요. Pace가 거기서 답하면 초기 설정이 끝나요.

업데이트와 삭제

업데이트하려면 brew upgrade --cask pacenote를 실행하세요. 새 버전이 나오면 앱이 알려 줘요. 삭제하려면 brew uninstall --cask pacenote를 실행하세요. 어느 쪽이든 설정과 실행 기록은 ~/.pacenote에 남으니, 함께 지우려면 그 폴더를 삭제하세요.

설치하기 전에

비용이 드나요?

Pacenote는 무료예요. 답변은 이미 쓰고 있는 Claude나 ChatGPT 요금제를 쓰고, 그 요금제의 한도에 포함돼요. Pacenote는 개인 프로젝트로, Apache License 2.0에 따른 오픈 소스이며 있는 그대로 제공돼요.

Slack 관리자가 필요한가요?

워크스페이스에서 앱을 만들고 설치할 수 있어야 해요. 워크스페이스에 따라 새 앱에 관리자 승인이 필요할 수도 있어요. 팀에서 Pacenote 허브를 운영한다면, 대신 내 Mac을 허브와 페어링하면 돼요. 앱은 허브에만 있으면 돼요. Linux 서버에 허브를 설치하는 명령 한 줄은 Pacenote가 만들어 줘요.

Intel Mac, Windows, Microsoft Teams에서도 되나요?

지금은 안 돼요. Pacenote는 Apple silicon Mac에서 돌아가고, Slack을 지원해요.
