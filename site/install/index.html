Install Pacenote

Three Homebrew commands, then a first run in the app that ends on your Todo. Pace, the Slack assistant, is there when you want it.

brew tap ashon/tap brew trust ashon/tap brew install --cask pacenote

What you need

  • An Apple silicon Mac on macOS 12 or later. The built-in sandbox needs macOS 15.
  • Claude Code on a Claude Pro, Max, Team or Enterprise plan, or Codex 0.138 or later on ChatGPT Plus, Pro or Business, signed in on that Mac.
  • To gather asks from Slack: Claude Code with your claude.ai account's Slack connector, or Codex with ChatGPT's Slack app. Pacenote reads Slack through it and holds no Slack token.
  • For Pace, the optional Slack assistant: a Slack workspace where you can create an app, or your team's Pacenote hub.

The first run ends on your Todo

  1. Install with Homebrew: add the tap with brew tap ashon/tap, trust it with brew trust ashon/tap, then run brew install --cask pacenote. Homebrew loads casks only from taps you trust, so without the trust it refuses the install.
  2. Open Pacenote. The first run asks for your AI, shows where your work is read from, and collects your last 7 days. Then Todo opens.
  3. For Pace in Slack, choose Set up Pace in Settings > General, or on the first run. It walks you through where answers run, Slack and a review, and is done when @Pace answers you in a thread.

Starting with your team

One person sets up a hub on a Linux server with Docker, and everyone else pairs with it. Only the hub needs a Slack app, so nobody else waits for an admin.

If you set up the hub

  1. Create the Slack app from Pacenote's manifest, with Socket Mode and an app token.
  2. In Settings > Messengers > Slack, open No hub yet?, give the address members will use, and copy the command.
  3. Paste it in the server's shell. It asks for the two tokens there, so they never leave the server. When the hub answers, your Pace switches to it.

If your team already has one

Open the link a teammate copies with Copy share link: it opens Pacenote with the hub filled in. Or choose Join your team's hub in setup, or Team hub in Settings > Messengers > Slack, and enter the address you were given. Then choose Connect, send the code Pacenote shows to @Pace in a channel it is in, and confirm in Pacenote that the account is yours.

Who can use the hub?

Everyone in the workspace, or only the Slack members you list when you copy the command.

Does it need a domain or HTTPS?

Not on your own network: http at a private address works. Anywhere else, serve it over HTTPS.

What if a teammate's Mac is off?

Their mention gets a note only they can see, saying their Pace is not connected.

How do I update it?

Copy the command again from the Pacenote you updated to, and run it. The tokens stay, and the hub takes that version.

Update or remove

Run brew upgrade --cask pacenote to update; the app tells you when a new version is out. If the upgrade skips Pacenote, trust the tap first with brew trust ashon/tap. Run brew uninstall --cask pacenote to remove it. Settings and run history stay in ~/.pacenote across both; delete that folder to remove them too.

Before you install

What does it cost?

Nothing for Pacenote. Answers use the Claude or ChatGPT plan you already have and count toward its limits. Pacenote is a personal project, open source under the Apache License 2.0 and offered as is.

Do I need my Slack admin?

You need to be able to create and install an app in your workspace, and some workspaces ask an admin to approve new apps. If your team runs a Pacenote hub, you pair your Mac with it instead: only the hub needs the app. See Starting with your team.

Does it work on Intel Macs, Windows or Microsoft Teams?

Not today. Pacenote runs on Apple silicon Macs and works with Slack.
