# Languages

Pacenote's own text reads in English and Korean: the app, its menus, tray and notifications, and the notes Pace posts
itself in Slack. English is the source and the default. Korean sits beside it in the same shape, and the type check
fails when a Korean message is missing.

What the AI writes is not Pacenote's text, but its prompts ask for the user's language, which is the app's. What the
user reads is written in it whatever language the messages are in: task titles, summaries and wrap-ups, the notes of
Looks done, recaps, and what the sessions Pacenote starts say to the user. Pace answers in the language of the request,
and in the user's language when the request does not show one. What other people read stays in theirs: a reply drafted
for a thread is in the thread's language. Names, code and quoted words stay as they are.

## Which language

| Text                                                                     | Language                                                                                                                     |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| The app: screens, menus, tray, notifications, dialogs                    | Settings > General > Language: macOS's (the default), or one chosen                                                          |
| What the app shows of Pace: setup issues, problems, checks               | The app's, passed to Pace as `PACENOTE_LOCALE` when it starts                                                                |
| What Pace posts itself in Slack: the line under answers, notes, failures | Settings > Answers > Pace's own notes (`NOTES_LANGUAGE`): the app's, or one chosen                                           |
| What the AI writes for the user (see above)                              | The app's: Pace is told it, and the app keeps it in `desktop.json` (`locale`) for Pacenote's MCP server (`src/i18n/user.ts`) |
| The team hub's notes in Slack                                            | `HUB_NOTES_LANGUAGE` on the hub (English)                                                                                    |

The app keeps its choice in `desktop.json` in the data folder. `PACENOTE_DESKTOP_LANGUAGE` stands in for macOS's
language, so end-to-end tests and screen captures pin it: the tests run in English.

These stay English: prompts and instructions for the AI, MCP tool names and descriptions, log lines, diagnostics for a
bug report, the terminal tools in `src/tools`, error text from the CLIs and the VM helper, the docs, the release notes
and the Homebrew cask. Run records are data that AI tools read through MCP, so the notes Pacenote writes into them stay
English; the app shows them in its language.

## Where text lives

A module's text is in a file beside it, named after it with `.text.ts` (`.text.tsx` when a message holds markup):

```ts
import type { Locale } from '../i18n/locale.js'

const en = {
  title: 'Run history',
  runs: (n: number) => `${n} ${n === 1 ? 'run' : 'runs'}`,
}

const ko: typeof en = {
  title: '실행 기록',
  runs: (n) => `실행 ${n}건`,
}

export const text: Record<Locale, typeof en> = { en, ko }
```

- A component reads it with `const t = useText(text)` (`@/lib/i18n`). Other code reads it with
  `const t = localized(text)` (`src/i18n/locale.ts`) inside the function that uses it, never at the top of a module:
  the language is read when the function runs. A map of labels kept as a constant becomes an entry in `text`.
- The settings screen's words are in `src/settings/fields.ko.ts`, by field key, group and section. Code that shows them
  reads `settingFields()`, `settingGroups()`, `settingSections()` or `settingLabel(key)`, not the English lists.
- The app's language changes while it runs: the window renders again from the top and the tray and menus are built
  again. Text is never worked out once and kept.

## Rules

- **Make text that holds a value a function.** Korean puts words in another order, so never join fragments such as
  `count + ' tasks'` or split a sentence across elements. A sentence with markup in it is one function that returns the
  markup.
- **Plurals belong to English.** The English function says `1 task` or `2 tasks`; Korean counts with a counter word:
  `할 일 2개`, `실행 3건`, `2명`, `3번`.
- **Particles after a value**: `josa(word, '을/를')` from `src/i18n/korean.ts` picks `을` or `를` by how the word ends,
  English names included (`Slack을`, `Codex를`). Or word the sentence so no particle follows the value.
- **Lists** with `listWords` (`src/i18n/words.ts`): `a, b and c`, `가, 나, 다`. Numbers with `formatNumber`, dates and
  times with `apps/web/src/lib/format.ts`; they follow the language.
- **Code never reads text.** Labels are not keys, and nothing compares or matches a message's words. Give the thing an
  id (`SlackCheckItem.id`, `RecapItem.run`, `LoginResult.cancelled`) and word it where it is shown.
- **The English stays the English.** Moving text into a `.text.ts` file keeps it as it was, since the tests and the
  end-to-end tests find the screens by their English.

## Korean style

- Write in the polite informal style (해요체): `저장했어요.`, `Pace를 다시 시작하면 적용돼요.` Ask with `-하세요` or
  `-해 주세요`.
- Buttons, menu items, tabs and labels are short nouns or verb stems with no ending: `저장`, `다시 시도`, `지금 모으기`,
  `설정 열기`.
- States read as states: `실행 중`, `중지됨`, `연결됨`, `설정 필요`.
- Pace speaks of itself in the first person, politely: `저는 저를 쓰는 분에게만 답해요.`
- Keep names as they are spelled: Pacenote, Pace, Slack, Claude Code, Codex, opencode, GitHub, Jira, Kubernetes, MCP,
  VM, Homebrew, macOS, Mac, Socket Mode. Keep setting keys, commands, paths and code as they are.
- macOS's own words are the ones Korean macOS uses: 시스템 설정, 일반, 로그인 항목, 개인정보 보호 및 보안, 로컬
  네트워크, 터미널, Finder. Slack's API site is in English, so its labels stay English: App-Level Token, Bot User
  OAuth Token, Socket Mode, OAuth & Permissions.

## Check both languages

- Settings > General > Language switches the app at once.
- `pnpm check` type-checks every Korean message against its English.
- `PACENOTE_DESKTOP_LANGUAGE=ko` opens the app in Korean whatever macOS's language, for a screen capture or a look.
