Pace가 내 MCP 서버를 쓸 수 있어요. 설정 > 도구에서 HTTP MCP 서버를 추가하거나, 이 Mac의 Claude Code나 Codex에 이미
있는 서버를 가져오면, Pace가 내장 샌드박스에서 답할 때 그 도구를 써요.

```sh
brew update && brew upgrade --cask pacenote
```

## 내 MCP 서버

- 설정 > 도구의 **MCP 서버**에 Pace가 쓸 수 있는 HTTP MCP 서버가 모여요. 이름, URL, 헤더(`Authorization: Bearer`
  토큰, API 키)로 직접 추가하거나, 이 Mac의 Claude Code와 Codex에 있는 서버를 한 번에 추가할 수 있어요. 한 번
  복사해 오는 방식이고, 다른 곳에 값이 있는 헤더는 그 자리에서 채워요.
- Pace가 내 Mac에서 각 서버에 연결해 모델 대신 호출하므로, 헤더와 토큰은 샌드박스에 들어가지 않아요. 나만 읽는
  파일에 보관하고, 화면에는 이름만 보여요.
- **읽기**는 서버가 읽기 전용으로 표시한 도구이고, 추가하면 켜져 있어요. **쓰기**는 그 밖의 모든 도구이고, 꺼진 채
  시작해요. **도구 확인**을 누르면 각 도구가 읽기인지 쓰기인지 보여서, 스위치마다 무엇이 열리는지 알 수 있어요.
- 이 Mac(`localhost`)이나 내 네트워크에 있는 서버도 되고, 그 줄에 표시돼요. 믿을 수 있는 서버만 추가하세요.
- 나에게만, 내장 샌드박스에서 쓰이고, 바꾼 내용은 재시작 없이 다음 답변부터 적용돼요. 내 Mac에서 프로그램으로
  실행되는 서버(stdio)와 OAuth로 로그인하는 서버는 아직 지원하지 않아요.
