설정 > 도구가 내 Mac에서 값을 찾아 줘요. 직접 입력하던 설정 아래에 이 Mac에 이미 있는 작업 폴더, GitHub 조직,
Kubernetes 컨텍스트, SSH 호스트를 보여 주고, 눌러서 고를 수 있어요.

```sh
brew update && brew upgrade --cask pacenote
```

## 입력하지 않고 고르기

- 설정 > 도구에서 연결을 열면, 설정마다 **이 Mac에서 찾음**에 여기서 찾은 이름이 나와요. 누르면 들어가고, 한 번 더
  누르면 빠져요. 고른 이름은 입력한 값처럼 저장하지 않은 변경이라, 저장과 되돌리기도 똑같이 동작해요.
- **작업 폴더**: 홈에서 저장소가 들어 있는 폴더를, 저장소 수와 함께 보여 줘요.
- **GitHub**: gh 로그인 계정과 그 계정이 속한 조직이에요. gh가 없으면 작업 폴더 저장소의 주인을 보여 줘요.
- **Kubernetes**: kubeconfig의 컨텍스트예요.
- **SSH 호스트**: SSH 설정(`Include`한 파일까지)에 있는 호스트의 사용자, 키, 사설 주소 범위예요. GitHub, GitLab,
  Bitbucket 같은 Git 호스팅과 이 Mac 안의 VM은 빼요.
- 이름과 경로만 읽어요. 키는 경로로만 찾고 열지 않아요. 폰과 iPad에는 이 이름들이 가지 않아요.
- gh에 로그인되어 있지 않거나 gh나 kubectl이 없으면, 그 설정에 무엇을 하면 되는지 알려 주고 **다시 찾기**를 둬요.
