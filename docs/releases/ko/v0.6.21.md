내장 샌드박스의 Codex로 답하는 Pace를 고쳤어요. MCP 도구가 콘솔 스크린샷 같은 이미지를 돌려주는 답변이 더는
"failed printing to stdout"으로 실패하지 않아요.

```sh
brew update && brew upgrade --cask pacenote
```

## 고친 점

- 내장 샌드박스에서 Codex를 쓸 때, 내 MCP 서버의 이미지처럼 도구가 큰 결과를 돌려주면 답변이
  `pacenote-vm exited with code 101`로 멈췄어요. 샌드박스의 바깥 연결이 답변의 출력을 함께 쓰면서 non-blocking으로
  바꿨고, 출력이 차자 Codex가 종료됐어요. 이제 답변마다 자기 출력을 따로 쓰므로, 결과가 Codex에 닿고 Pace가 답해요.
