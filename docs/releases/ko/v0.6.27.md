nvm 같은 버전 관리자로 설치한 Claude Code, Codex, opencode를 이 Mac에 없다고 하던 문제를 고쳤어요.

```sh
brew update && brew upgrade --cask pacenote
```

## 고친 점

- Pacenote는 로그인 셸이 알려 주는 PATH로 CLI를 실행해요. 셸이 node를 처음 실행할 때에야 nvm을 불러오거나 시작에
  5초 넘게 걸리면 `~/.nvm`에 설치한 CLI가 PATH에서 빠져서, 설정과 회고의 정리하기, 지금 모으기가 Codex(또는
  Claude Code)가 이 Mac에 없다고 했어요. 이제 버전 관리자와 설치 도구가 CLI를 두는 곳도 함께 찾아요. nvm의 node
  버전(기본 버전 먼저), fnm, Volta, asdf, mise, Bun, `~/.local/bin`, Homebrew, `/usr/local/bin`이에요.
