세션 페이지에 Claude Code가 지금 하는 일이 보이고, 대화가 대화답게 보여요. 답은 마크다운으로, 단계는 한 일에 따라,
Claude Code가 내 메시지에 덧붙이는 내용은 원래 뜻대로 보여요.

```sh
brew update && brew upgrade --cask pacenote
```

## 지금 하는 일

- Pacenote가 실행한 세션이 차례를 진행하는 동안, 페이지 맨 아래에 지금 하는 일과 걸린 시간이 보여요. **생각하는
  중**인지, 어떤 단계를 실행 중인지, 아니면 답을 쓰는 중인지요. 답은 써지는 대로 보여요.
- 터미널이나 다른 앱에서 열린 세션은 거기서 작업 중이라고 알려 줘요.

## 대화

- 답은 **마크다운**으로 보여요. 제목, 목록, 굵게, 코드까지요.
- 단계는 한 일에 따라 보여요(명령, 파일 읽기나 수정, 검색, 웹 페이지, MCP 도구). 경로는 세션 폴더 기준으로 짧게
  보여요. 실패한 단계에는 **실패**가 붙어요. 네 개 이상 이어지면 "단계 4개 · Read 2 · Grep · Bash"처럼 한 줄로 접히고,
  누르면 펼쳐져요.
- Claude Code가 내 메시지에 덧붙이는 내용도 원래 뜻대로 보여요. 슬래시 명령과 출력, `!`로 실행한 명령과 출력,
  백그라운드 작업 알림, 내가 멈춘 차례, 보낸 이미지가 그래요. 긴 세션을 Claude Code가 압축했을 때 남긴 요약은 접어서
  보여요.
- Claude Code가 모델에게 남기는 알림과 자체 기록 줄은 보이지 않아요.
- 할 일의 세션 로그도 같은 모습으로 보여요.
