세션이 claude.ai에 올린 것이 세션 페이지에 카드로 보여서 한 번에 열 수 있어요. 개요의 일별 토큰은 Pacenote가 진행한
세션과 할 일을 도운 몫도 세요.

```sh
brew update && brew upgrade --cask pacenote
```

## 세션이 만든 것

- Claude Code 세션이 claude.ai에 올린 페이지, 디자인, 문서가 대화 속 마지막으로 올린 자리에 카드로 보여요. 무엇인지,
  버전, 세션에서 몇 번 고쳤는지, 나만 열 수 있으면 **나만**이 함께 나와요.
- Codex 세션은 답에 링크한 세션 폴더 안 파일이 카드가 돼요. HTML 페이지, 이미지, PDF, Markdown이에요.
- 세션 제목 아래 **만든 것**에서 전부 볼 수 있어요.
- 링크는 내 브라우저에서 내 로그인으로 열려요. 파일은 이 Mac의 앱이나 Finder에서 열려요.
- 할 일 상세에 세션들이 만든 것을 모은 **만든 것** 줄이 생겼어요. 나만 열 수 있는 것이 있으면 링크를 보내기 전에
  claude.ai에서 공유하라고 알려줘요. 할 일의 답장 초안에는 그 일로 만든 것의 링크가 들어가요.
- Pacenote는 이 모두를 세션의 로그에서만 읽어요. 링크만 가지고 있고, claude.ai를 직접 열지 않아요.

## 일별 토큰

- 개요의 **일별 토큰**에 두 가지가 더해졌어요. **세션**은 Pacenote가 진행한 Claude Code 세션의 턴이고, **할 일 돕기**는
  새로 넣은 할 일 채우기, 끝남 확인, 답장 초안이에요.
- **출처별**에는 턴을 몇 번 진행했고 턴당 얼마를 썼는지, 할 일을 몇 번 채우고 끝남을 확인하고 초안을 썼는지 나와요.
- 이번 버전부터 세기 시작해서, 그 전 날짜에는 나오지 않아요.

## 폰이나 iPad에서

- 폰이나 iPad의 세션 페이지에서도 앱의 다음 빌드부터 같은 카드가 보여요. 파일은 이름만 나와요.
