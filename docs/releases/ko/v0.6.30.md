Pacenote에서 Claude Code 세션과 대화해요. 세션을 열면 대화가 진행되는 대로 보이고, 거기서 바로 메시지를 보내고
세션이 묻는 것에 답할 수 있어요.

```sh
brew update && brew upgrade --cask pacenote
```

## 세션 페이지

- **세션**의 세션이나 할 일의 세션 줄에서 **열기**를 누르면 Pacenote 안에서 대화가 진행되는 대로 보여요. 내가 보낸
  메시지, 답, 지금 하고 있는 단계까지요. **에서 보기**는 지금처럼 세션이 도는 앱을 앞으로 가져와요.
- 다른 곳에서 열려 있지 않은 Claude Code 세션은 **페이지에서 이어서** 할 수 있어요. Pacenote가 설치된 `claude`를 내
  로그인으로, 세션이 돌던 폴더에서 그 세션의 대화를 이어서 실행해요. 대화는 늘 그렇듯 Claude Code의 로그에 남아서
  나중에 어디서든 `claude --resume`으로 이어 갈 수 있고, Pacenote는 아무것도 따로 저장하지 않아요.
- 명령 실행, 파일 수정, 페이지 가져오기, 계획대로 진행을 물으면 무엇을 어느 폴더에서 하려는지 페이지에 보여요.
  **허용**, **이 세션에서 … 계속 허용**(그 실행에만, 설정에는 쓰지 않아요), **거절** 중에 고르면 돼요. 대신 메시지를
  보내면 거절하고 무엇을 할지 알려 줘요. Pacenote가 가려져 있으면 알림으로 알려 줘요.
- 입력창 아래에서 행동하기 전에 어떻게 물을지(바꾸기 전에 묻기, 묻지 않고 바꾸기, 먼저 계획, 자동) 고르고,
  **멈추기**로 지금 하던 차례를 멈춰요.
- **터미널**, Claude 앱, claude.ai에서 열려 있는 세션은 진행되는 대로 보여 주고, 메시지는 거기서 보내요. 두 곳에서
  한 세션에 입력하면 꼬이기 때문이에요. **여기서 복사본으로 잇기**를 누르면 같은 할 일에 연결된 복사본을
  Pacenote에서 시작해요.
- Pacenote가 실행한 세션은 창을 닫아도 계속 돌고, 페이지 메뉴의 **여기서 끝내기**로 끝내거나 30분 동안 할 일이
  없으면 끝나요. 차례를 진행 중인 세션이 있을 때 Pacenote를 종료하면 먼저 물어봐요.
- Codex 세션도 페이지에서 볼 수 있어요. 메시지는 Codex에서 보내요.
