Pacenote 0.7은 내 세션이 Pacenote 안으로 들어온 것을 표시해요. Mac의 Claude Code와 Codex 세션이 한곳에 모이고, 세션마다
이어 갈 수 있는 페이지가 있고, 그 세션의 할 일과 이어져요.

```sh
brew update && brew upgrade --cask pacenote
```

## 0.6.52에서 올라오면

앱은 0.6.52에서 한 줄만 고쳤어요. 첫 실행의 내 프로젝트 단계가 나중에 고칠 곳을 0.6.45부터 쓰는 화면 이름인 **영역**으로
알려 줘요. pacenote.dev 가이드에 [세션](https://pacenote.dev/ko/guide/sessions/) 페이지가 생겼고, 전체 이야기는
[내 세션을 Pacenote 안에서](https://pacenote.dev/ko/news/sessions-in-pacenote/) 글에 있어요. 개인정보 페이지에는 AI가
할 일을 채우거나 묶을 때, 할 일을 마무리할 때, 세션에 입력한 말을 전할 때 AI로 가는 것과, 내 다른 Mac에 보이는 세션을
더했어요.

## 세션이 들어온 과정

- 0.6.28: **세션** 화면이 이 Mac의 Claude Code와 Codex 세션을 보여 줘요. 어디서 도는지, 나를 기다리는지요.
- 0.6.29: 내가 직접 시작한 세션이 그 세션이 작업한 할 일에 연결돼요.
- 0.6.30, 0.6.31: Pacenote 안의 세션 페이지에서 입력하고, 세션이 지금 하는 일을 봐요.
- 0.6.32: **여기서 계속**이 Pacenote에서 세션을 시작하고, 다른 도구는 옆 메뉴에 있어요.
- 0.6.34 ~ 0.6.36: 대화 하나가 마지막으로 입력한 곳에서 이어지고, 세션 페이지가 AI 채팅처럼 동작해요.
- 0.6.38: 내 다른 Mac의 세션, 그리고 세션 페이지 옆의 내 세션 목록.
- 0.6.40, 0.6.42: 세션이 claude.ai에 만든 것, 메시지와 함께 보내는 이미지.
- 0.6.43: Pacenote 안의 Codex 세션, **닫기**와 **마무리**.
- 0.6.50: 세션에 넘긴 할 일이 카드로 보이고, 보내는 말에 Markdown을 써요.
- 0.6.52: 두고 간 세션은 쉬고, 닫기 전까지 열려 있어요.

- ⌘를 누르고 있으면 컨트롤마다 단축키가 보여요(0.6.50).
