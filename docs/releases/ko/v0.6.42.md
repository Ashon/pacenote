Pacenote에서 Claude Code 세션에 보내는 메시지에 이미지를 함께 넣을 수 있어요. 스크린샷을 붙여 넣거나, 파일을
끌어다 놓거나, 골라서 넣으면 입력한 내용과 함께 가요.

```sh
brew update && brew upgrade --cask pacenote
```

## 메시지와 함께 가는 이미지

- 세션의 입력창에 이미지를 붙여 넣거나, 끌어다 놓거나, 이미지 버튼으로 골라요. PNG, JPEG, GIF, WebP를 한 메시지에
  10장까지 넣을 수 있어요. 넣은 이미지는 입력창 위에 보이고, 버튼으로 뺄 수 있어요.
- 한 장은 긴 변 1568픽셀, 1MB까지 가요. Claude가 보는 만큼이에요. 더 큰 이미지는 가는 길에 줄여요. 다른 종류의
  파일은 빼고, 왜 뺐는지 입력창에 알려 줘요.
- 이미지는 Claude Code에 직접 붙여 넣은 것처럼 가서 Claude Code의 로그에 남아요. Pacenote는 따로 보관하지 않아요.
- 내 턴에 이미지가 보이고, 누르면 크게 열려요.
- 세션이 무언가를 묻는 중이면 그 답에는 이미지를 넣을 수 없어요.

## 답을 받는 동안

- 세션 페이지는 새 내용이 들어오는 동안, 이미지가 연달아 불러와질 때도 맨 끝에 머물러요. 내가 직접 위로 올릴 때만
  끝을 떠나요.

## 다른 Mac, 폰, iPad

- 턴에 이미지가 몇 장 있었는지 보여 줘요. 폰과 iPad는 앱의 다음 빌드부터예요. 폰과 iPad에서 보내는 메시지에는
  이미지를 넣을 수 없어요.
