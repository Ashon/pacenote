스크롤바가 화면 바탕의 둥근 모서리에 닿으면 잘리지 않고 모서리를 따라 휘어요.

```sh
brew update && brew upgrade --cask pacenote
```

## 스크롤

- 화면의 스크롤바가 바탕의 둥근 모서리에 닿는 위아래 끝에서, 막대가 모서리에 잘리지 않고 곡선을 따라 휘어요.
  끝까지 다 돌지 않고 일부만 휘어서, 맨 위나 맨 아래에서도 막대는 옆에 서 있고 끝만 곡선을 따라가요.
- 목록 옆이나 코드 블록처럼 모서리에 닿지 않는 스크롤바는 그대로 곧게 있어요.

## 폰과 iPad

- 폰과 iPad는 각자의 스크롤을 그대로 써요. 달라지는 건 없어요.
