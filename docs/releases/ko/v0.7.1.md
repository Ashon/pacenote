긴 세션이 빨리 열리고 끊기지 않아요. 아무리 빨리 보내도 세션은 한 번만 실행되고, 동작마다 이름이 하나로 정해졌어요.

```sh
brew update && brew upgrade --cask pacenote
```

## 세션

- 세션 페이지가 마지막으로 본 뒤에 로그에 새로 쓰인 부분만 읽어요. 350MB 로그는 작업하는 동안 볼 때마다 2초 가까이
  걸렸는데, 이제 처음 한 번 뒤로는 1밀리초도 안 걸려요. 512MB가 넘는 로그는 아예 열리지 않았는데, 이제 1초쯤이면
  열려요.
- 세션이 로그에서 다시 이어지는 동안 메시지를 연달아 두 번 보내도 실행은 하나만 시작돼요.
- **여기서 복사본으로 잇기**가 시작하지 못하면 복사본만 끝나요. 원본 세션은 계속 돌아요.
- 대화의 시각이 오늘은 14:03, 그 전은 11/27 14:03으로 보여요. 초는 마우스를 올리면 나와요.
- Pacenote가 모르는 도구의 단계는 JSON 대신 그 단계가 말하는 내용을 보여 줘요.
- 입력창 아래 안내가 한 문장이 됐어요. 대화가 어디에 보관되는지는 마우스를 올리면 나와요.
- 세션 페이지 옆 목록에서 내 차례인 세션의 점이 더 크고 테두리가 있어서 작업 중인 세션과 구분돼요.

## 동작마다 이름 하나

- 끝난 것 같은 할 일은 할 일 행과 같은 **완료**를 보여 줘요(전에는 닫기).
- 할 일에서 연 세션 로그는 **로그 접기**로 접어요(전에는 로그 닫기).
- 세션이 claude.ai에 만든 페이지나 문서는 **claude.ai에서 열기**로 열어요.
- 마무리 시트의 영어 문구를 더 쉽게 다듬었어요.
