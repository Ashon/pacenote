## Pace 마크와 도구

- Runs에서 Pace 답변의 Pace 마크 오른쪽 아래에 그 실행에 쓴 도구(Claude Code 또는 Codex)를 나타내는 작은 원이 붙어요.
  마우스를 올리면 도구와 모델이 보여요.
- 세션 페이지의 답변에도 도구 첫 글자 대신 같은 마크와 원이 붙어요. 답변을 쓰는 동안에는 마크가 움직이고 원은 그대로
  있어요.
- opencode 세션에는 원 없이 Pace 마크만 보여요.
