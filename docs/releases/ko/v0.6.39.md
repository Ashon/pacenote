Pacenote 창이 회색이 됐어요. 고른 색은 버튼, 선택한 항목, Pace의 마크처럼 가리키는 곳에만 보여요.

```sh
brew update && brew upgrade --cask pacenote
```

## 가리키는 곳에만 색

- 창의 바탕, 사이드바, 카드, 테두리, 글자, 그림자가 라이트와 다크 모두 회색이에요. 설정 > 일반에서 어떤 색을 골라도
  같아요. 창 전체에 색조가 깔려 있으면 눈이 쉽게 피로했어요.
- 고른 색은 버튼, 선택한 줄과 포인터가 올라간 줄, 포커스 테두리, 강조한 카드, 차트, Pace의 마크와 스피너에 남아요.
  상태 색은 그대로예요.
- 밝기는 그대로라서 글자는 전처럼 읽히고, 카드도 전처럼 창과 구분돼요.
- Pace가 Slack에 올리는 다이어그램은 pacenote.dev처럼 초록 선 그대로예요.

- 앱 빌드 536도 같은 회색 창이에요.
