세션 화면에 내 다른 Mac의 세션도 보여요. 세션 페이지를 열면 설정 화면처럼 왼쪽에 세션 목록이 함께 보여요.

```sh
brew update && brew upgrade --cask pacenote
```

## 내 다른 Mac의 세션

- 세션 화면에 **이 Mac** 다음으로, 이 Mac과 이어진 Mac마다 그 이름 아래에 세션이 보여요. 열려 있는 세션은 프로젝트별로,
  오늘 끝난 세션은 **오늘 끝남**에 보여요. 볼 때마다 그 Mac에서 읽어 와요.
- 세션을 열면 대화와 지금 하는 일이 오는 대로 보여요. 입력하고, 묻는 것에 답하고, 멈추는 일은 그 세션이 있는 Mac에서
  해요. 페이지에도 그렇게 나와요.
- 다른 Mac은 세션을 보기만 해요. 이 Mac의 세션에 보내거나, 답하거나, 멈추거나, 할 일에 이을 수 없어요.
- 세션은 그 Mac에서 세션이 켜져 있을 때 보여요(설정 > 할 일 > 이 Mac의 세션). 두 Mac 모두 이 버전이어야 하고, 이전
  버전인 Mac은 업데이트가 필요하다고 보여요. 세션 내용은 이미 이어져 있는 연결로 내 Mac과 기기에만 가요.

## 세션 페이지 옆에

- 세션 페이지와 **새 세션**의 왼쪽에 세션 목록이 보여요. 이 Mac의 열린 세션이 프로젝트별로, 다른 Mac의 세션이 그
  이름 아래에, 그다음에 오늘 끝난 세션이 오고, 지금 연 세션이 표시돼요. 위쪽 **세션**을 누르면 전체 화면으로 돌아가고,
  **+**로 새 세션을 시작해요. 창이 좁으면 목록은 빠져요.

## 폰이나 iPad에서

- 앱 빌드 534에서는 iPad의 세션 페이지 옆에도 목록이 보여요. 폰은 지금처럼 한 번에 한 화면씩 보여요.
- 폰이나 iPad는 연결한 Mac의 세션을 보여 줘요. 다른 Mac의 세션은 Mac에서 보여요.
