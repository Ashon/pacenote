Claude Code와 Codex 세션을 한곳에서 봐요. 새 세션 화면이 이 Mac에 열린 세션과 각 세션이 어디서 도는지, 어느 세션이
내 차례인지 보여 줘요.

```sh
brew update && brew upgrade --cask pacenote
```

## 이 Mac의 세션

- 사이드바의 할 일 아래 **세션**은 켜기 전까지 꺼져 있어요. 카드가 먼저 무엇을 찾았는지(열린 Claude Code 세션 수와
  어디서 도는지, 오늘 로그를 쓴 Codex 세션 수)와 무엇을 읽는지 알려 줘요.
- 세션은 그 세션이 다루는 저장소가 속한 나(You)의 영역별로, 없으면 저장소별로 묶여요. 세션마다 어디서 도는지(Claude
  앱, claude.ai, 시작한 터미널이나 편집기 앱, Codex 앱), **작업 중**인지 **내 차례**인지 조용한지, 브랜치, 연결된 할
  일, 마지막으로 입력한 말을 보여 줘요.
- 사이드바에 내 차례인 세션 수가 떠요.
- 세션을 펼치면 최근에 입력한 말, 폴더, 시작한 때, 로그(볼 때만 읽어요), 터미널에서 이어 가는 명령이 나와요.
  **Claude에서 열기**, **claude.ai에서 열기**, **Codex에서 열기**, 터미널 앱**에서 보기**를 누르면 세션이 도는 곳으로
  가요.
- **오늘 끝남**에는 자정 이후에 닫힌 Claude Code 세션이 있어요.
- 열린 세션은 Claude Code의 목록(`claude agents`)과 오늘의 Codex 로그에서 가져와요. `codex exec` 실행과 하위 에이전트는
  빼요. opencode 세션은 다음에 넣을게요.
- 읽은 것은 이 Mac 밖으로 나가지 않고, 폰과 다른 기기에는 세션이 보이지 않아요.

## 달라진 점

- 세션을 할 일에 연결하던 **설정 > 할 일**의 스위치 이름이 **이 Mac의 세션**으로 바뀌었어요. 이 화면도 함께 켜기
  때문이에요. 켜 둔 값은 그대로예요.
- 압축된 세션의 요약이 더 이상 내가 입력한 말로 보이지 않아요.
