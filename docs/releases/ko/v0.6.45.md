"나" 화면이 "영역"이 됐고, 세션의 "최신으로" 버튼이 유리처럼 보여요.

```sh
brew update && brew upgrade --cask pacenote
```

## 영역

- 내가 기여하는 곳을 보여 주는 화면의 이름이 **나**에서 **영역**으로 바뀌었고, 아이콘도 새로 생겼어요. 위치와 내용은
  그대로예요. 내 영역마다 내가 하는 역할, 열린 할 일, 최근에 한 일이 보여요.
- 할 일 화면의 첫 안내와 회고의 영역 링크도 같은 이름으로 불러요.

## 세션

- 세션 페이지를 맨 아래로 돌려 주는 **최신으로** 버튼이 대화 위에 뜬 반투명 유리처럼 보여요. 버튼 뒤가 흐려지고
  그림자가 생겨서 라이트와 다크 모두에서 잘 보여요. 전에는 그림자가 없었고, 다크 모드에서는 배경도 거의 비어 있었어요.
