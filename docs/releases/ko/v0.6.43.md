Pacenote의 세션을 Codex로도 열 수 있어요. 세션 페이지에서 세션을 닫거나 할 일로 마무리할 수 있고, 묶인 할 일은
그룹째로 접혀요.

```sh
brew update && brew upgrade --cask pacenote
```

## Pacenote에서 여는 Codex 세션

- **새 세션**과 할 일의 **여기서 계속**에서 Claude Code와 Codex 중 하나를 골라요. 마지막에 고른 쪽이 남아요.
  Codex는 이 Mac에 0.163 이상이 있고 로그인되어 있으면 보여요.
- Pacenote는 내 ChatGPT 로그인으로 세션마다 `codex app-server`를 실행해요. 대화는 Codex의 로그에 남아서, 나중에
  어디서든 `codex resume`으로 이어 갈 수 있어요.
- 페이지에서는 Claude Code 세션처럼 이어 가요. 진행 상황이 실시간으로 보이고, 멈출 수 있고, 메시지에 이미지를 넣을
  수 있어요. 단계도 같은 모양으로 읽혀서 명령은 Shell, 패치는 Edit로 보여요.
- 모드는 Codex의 것을 그대로 써요. 읽기만, 폴더 밖은 묻기(기본), 전체 접근 중에서 고르고, 바꾼 모드는 다음 턴부터
  적용돼요. Codex가 묻는 것(명령, 파일 변경, 네트워크나 쓰기 권한)에는 Codex가 적은 이유가 함께 와요.
- Codex 앱이나 터미널에서 실행 중인 세션은 그곳에서 이어 가요.

## 닫기와 마무리

- 세션 제목 옆의 **닫기**는 Pacenote가 실행하는 세션이나 Codex 세션의 실행을 여기서 끝내요. 세션은 **오늘 끝남**으로
  옮겨 가고, 다시 말을 걸 때처럼 로그에 새로 쓰이면 다시 열려요. 대화는 도구가 그대로 가지고 있어요.
- 열린 할 일의 작업인 세션에는 제목 옆에 **마무리**가 있어요. 내 AI가 세션의 마지막 턴(과 브랜치의 PR)을 읽고 한
  일과 남은 일을 적어 줘요. 고친 다음 남은 일 중 할 일로 남길 것을 체크하면 할 일이 그 내용으로 닫혀요. 열어 두기로
  하지 않으면 세션도 함께 닫혀요.
- 오늘 로그에 쓰인 Codex 세션이 하루 내내 열린 채로 남지 않아요. 닫을 때까지만 열려 있어요.

## 할 일 그룹

- 그룹의 화살표를 누르면 그룹과 요약, 그 안의 할 일이 함께 접히고, 할 일 화면이 접힌 상태를 기억해요. 그룹 안의
  할 일 하나가 열려 있는 동안에는 그룹도 열려 있어요.

## 폰과 iPad

- Codex 세션 시작, 닫기, 마무리는 지금은 Mac에서만 돼요. 폰과 iPad는 다음 빌드에서 받아요.
