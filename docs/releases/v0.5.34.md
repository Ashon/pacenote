Upgrading no longer ends in "Pacenote could not start".

```sh
brew update && brew upgrade --cask pacenote
```

## Upgrades

- **No error as the new version comes in.** Homebrew asks Pacenote to quit until it is gone, and an ask that came just
  after could open the old version again while the upgrade moved its files away, so it said "Pacenote could not start".
  That copy now goes quietly and opens the new version once it is in place. The old version is the one running during
  an upgrade, so this shows from the next upgrade after this one.
