Upgrades no longer leave Pacenote closed.

```sh
brew update && brew upgrade --cask pacenote
```

If `brew upgrade` skips Pacenote, run `brew trust ashon/tap` once: Homebrew upgrades casks only from taps you trust.

## Upgrading

- **Opened only to be told to quit, it goes at once.** Homebrew quits Pacenote before an upgrade by asking again and
  again until it is gone, and a request that finds it gone opens it first. That copy started Pace before the request
  came, so Homebrew kept finding it running, gave up after 10 seconds ("did not quit") and left the new version closed.
  Opened within 5 seconds of a quit, Pacenote now waits 2 seconds for a quit request before it starts anything and goes
  at once if one comes, so Homebrew finds it gone and opens the new version.
- The old version is the one running during an upgrade, so the upgrade to this version can still end with Pacenote
  closed: open it once the upgrade is done, or quit Pacenote before you upgrade. Upgrades after it reopen it.
