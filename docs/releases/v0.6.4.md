A team hub on your own network no longer needs a certificate first: Pacenote takes its http:// address there.

```sh
brew update && brew upgrade --cask pacenote
```

## Team hub

- **http on your own network.** In setup and in Settings > Messengers > Slack > Team hub, a hub's address can now start
  with http:// when it is a private address (10.x, 172.16-31.x, 192.168.x, Tailscale's 100.64.x) or a name that exists
  only there (`hub.local`, `hub.internal`, a name without a dot). Publish the hub's port on that network (`"8790:8790"`
  in `compose.yaml`) and set `HUB_PUBLIC_URL` to the same address. The hub token and the threads then cross that
  network unencrypted; anywhere else the hub still needs https.
