Settings > Tools shows what Pace can reach when it answers you, and each connection now has a Read and a Write switch.

```sh
brew update && brew upgrade --cask pacenote
```

## Tools

- **One place.** Ops tools is now Settings > Tools. A line on top says what Pace can reach now ("Pace can read your
  work folder and GitHub, and write to GitHub."), and the reference folder and the allowed domains moved in from
  Answers and Sandbox.
- **Connections open in place.** The work folder, GitHub, Jira, Kubernetes and SSH hosts are rows that say what each
  reaches, whether Pace reads and writes there, and what is left to fill in. A row opens on its settings, with what Pace
  never does there.
- **Read and Write.** Each connection has a Read switch, and GitHub and Jira a Write switch: draft PRs, and issues and
  comments. A connection you set up from now on starts with Write off; GitHub and Jira already set up keep writing as
  they did.
- **Off means gone.** Pace is offered only the tools the switches allow, its broker reaches only the connections in use,
  and when a request needs one that is off, Pace says what to allow in Settings > Tools.
- **Follows as you flip.** The line on top and the row change before you save, and the Broker card checks only the
  connections in use.
