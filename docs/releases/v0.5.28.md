Pacenote runs on Electron 43, with the security fixes Electron 39 no longer gets, and Todo's rows sit still when they load.

```sh
brew update && brew upgrade --cask pacenote
```

## Security

- **Electron 43.** The app moves from Electron 39 to 43 (Chromium 150, Node 24), a line that still gets fixes. It
  closes four Electron advisories: popups and windows that dropped the sandbox restrictions of the page that opened
  them, file and HTTP handlers that allowed cross-origin reads, and Node.js in a `<webview>`'s workers.
- **Notifications go through macOS's current API.** Pacenote is signed, so its notifications show as before; if macOS
  asks, allow them in System Settings > Notifications.
- **Build tools.** vite 6.4.4 and a patched CSS selector parser, for the app's own build. Nothing you run changes.

## Also

- **Todo holds still.** Each task row grew a pixel when the list finished loading, since v0.5.27's type roles; the
  placeholder rows are now exactly as tall.
