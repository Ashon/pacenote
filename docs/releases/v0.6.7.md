Todo works with opencode too: add Pacenote to it, and continue code tasks in it.

```sh
brew update && brew upgrade --cask pacenote
```

## Todo

- **Pacenote in opencode.** Settings > Todo lists opencode beside Claude Code and Codex: one click adds Pacenote's MCP
  server to opencode's global config, puts this app in place of another, or takes it out. opencode cannot take a server
  out itself, so Pacenote edits its config file, and the file's comments stay as they were.
- **Every repository you work in.** Repository folders lists the repositories of your open tasks and of the folders you
  worked in lately, not only the folders you chose. Each says whether it opens in a folder you chose, one found where you
  worked lately, or none yet, and how many open tasks it has.
- **Continue code tasks in opencode.** Open code tasks in takes opencode. Continue opens it in your terminal with the
  task, as opencode has no app to write the task into. While Todo is open, Pacenote finds the session through opencode's
  CLI, says when it last wrote, reads its log and "looks done" from it, and continues it with `opencode --session`.
- **Each tool that is here.** A task's menu offers every other tool installed on this Mac, opencode once its CLI is on
  the PATH.
