Pacenote is open source under the Apache License 2.0, and an upgrade no longer leaves the old version running with Pace
stopped.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first and reopens it, once. The fix below works from this version on, so if Pace has
stopped after this upgrade, quit Pacenote and open it again.

## Upgrades

- **No old copy left behind.** Homebrew asks the running app to quit until it is gone, and a late request could open
  the old version again just as the new one moved in. That copy ran Pace from files that were no longer its own, and
  Pace stopped. Pacenote now sees a new version on disk within seconds, stops Pace as on any quit, and opens as the new
  version. Opened from an app already replaced, it goes straight on to the new version.
