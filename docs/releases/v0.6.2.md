Pacenote does the same work with less: the app reads and redraws less, Pace answers a little sooner, and a few rare
glitches are gone.

```sh
brew update && brew upgrade --cask pacenote
```

## Todo

- **A task's buttons stay in place.** The link to a task's message now sits just before Done, as an outline button like
  Continue in Claude Code and Draft a reply, so Done, Dismiss and More line up in every row, with a link or without.

## Lighter and quicker

- **The app reads less.** It reads settings.json again only once it changes, reads each task file once per refresh, and
  leaves the work file alone when nothing changed, so an open window no longer refreshes every 30 seconds for nothing.
- **Fewer CLI checks.** Settings > Todo checks Claude Code, Codex and opencode again only when their state moved, not on
  every change to a task, and checks that overlap share one run.
- **The window draws less.** Pace's log keeps its lines on screen as new ones come in instead of drawing them all again,
  Markdown is read again only when it changes, Settings builds only the section on screen, and dates are written far
  faster.
- **Pace answers a little sooner.** It reads the conversation while it opens the run, changes its reactions together,
  and looks up the files shared in a thread together.
- **No pause while the ops tools start.** Pace no longer stops answering for up to 45 seconds while the ops tools' VM
  reads the gh login and the git author.
- **Run history** reads a thread's runs from the days since the thread began, and the app lets go of the runs Pace has
  cleared away.

## Fixes

- Korean and other non-Latin text that a CLI's output split between two reads no longer turns into "�".
- A diagram Pace could not draw keeps the `$` signs in its source as written.
- A long connection to the team hub no longer piles up timers.
