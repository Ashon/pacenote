A code task now continues here: **Continue here** starts a Claude Code session in Pacenote with what came before, and
Claude Code, Codex and opencode sit in its menu. Sheets round with your window's corners.

```sh
brew update && brew upgrade --cask pacenote
```

## Continue here

- A code task's first button is **Continue here**. It opens a new session page with the task and what came before it
  written in as the first message, the task's repository on this Mac as its folder, and how Claude Code asks before it
  acts. Change any of them, then **Start** (or ⌘↩): Pacenote runs your installed `claude` there, with your own sign-in,
  and the session's page opens in place.
- The session is the task's work from the start, named after the task, so its work log has it and you talk to it on its
  page as for any session Pacenote runs.
- It needs Sessions on this Mac; the page turns it on with one button.

## The other apps, in its menu

- The arrow beside it, **Continue in another app**, lists Claude Code, Codex and opencode, each saying where it opens: a
  terminal or the tool's desktop app, as **Open sessions in** says (Settings > Todo). The tool set in **Open code tasks
  in** comes first.
- A task that is not code has **Continue here** first in its menu.

## Sessions

- Sessions has **New session**: one in any folder you choose, with a first message of yours.
- A task's session log goes on with a session Pacenote runs on its page: **Continue here** opens it, rather than a
  terminal beside it.

## Sheets

- Sheets that slide in from the right keep an even margin from the window's edges and round concentric with its
  corners, on macOS 26 and on earlier versions. In full screen they keep their usual corners.
