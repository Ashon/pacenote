A fix for Claude Code, Codex and opencode installed with nvm or another version manager: Pacenote no longer says they
aren't on this Mac.

```sh
brew update && brew upgrade --cask pacenote
```

## Fixes

- Pacenote runs your CLIs with the PATH your login shell gives it. When the shell loads nvm only once node is first
  run, or takes longer than 5 seconds to start, a CLI installed under `~/.nvm` was left out, so Settings, Write it up
  in Recap and Collect now said Codex (or Claude Code) wasn't on this Mac. Pacenote now also looks where version
  managers and installers put CLIs: nvm's node versions (its default first), fnm, Volta, asdf, mise, Bun,
  `~/.local/bin`, Homebrew and `/usr/local/bin`.
