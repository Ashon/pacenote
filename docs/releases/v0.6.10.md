Security fixes in the libraries Pacenote carries.

```sh
brew update && brew upgrade --cask pacenote
```

## Fixes

- **undici 8.12.3**, which Pace's Slack connection (Socket Mode) uses: fixes for denials of service and an integrity
  check bypass (GHSA-4qv8-2p9j-2685, GHSA-f72v-6w45-q472, GHSA-xjj6-f33q-929c).
- **body-parser 2.4.0**, in the MCP and Slack libraries Pacenote bundles: a denial of service fix
  (GHSA-27r3-jxmh-p828).
- **fast-uri 3.1.9**, under the MCP library's schema checks: fixes for how some URIs are read (GHSA-333x-w4r6-6crp,
  GHSA-w74x-v6f9-j3xg, GHSA-xhq7-xmqj-769h, GHSA-wjr9-j795-jxcr).
