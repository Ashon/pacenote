## Recap

- **Write it up** now gives each area its own heading, with what you did there as a few short bullets under it, most
  work first. What is still open comes last, in a block of its own.
- An area's heading opens it on Areas.
- Copy has the write-up as each area's name over its bullets, in Markdown or for Slack. **The summary only** copies
  just that.
- A write-up from before stays as it was written. **Write again** writes it the new way.

## Sessions

- Starting a session, your first message showed twice for a second or two and then once. Claude Code writes it to the
  session's log before it says it has read it, and the page showed both. It shows once now, from the moment it is in
  the log.
