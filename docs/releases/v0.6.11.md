Share your team hub with a link, and read how Pacenote works on pacenote.dev.

```sh
brew update && brew upgrade --cask pacenote
```

## Team hub

- **Share with teammates.** Once paired, Settings > Messengers > Slack has **Copy share link**: a link to
  pacenote.dev's join page that opens a teammate's Pacenote with the hub filled in, or shows them how to install it
  first. Slack and mail make it clickable, where a `pacenote://` link may not be.
- **The address stays in the browser.** The hub's address is after the `#` in the link, which browsers never send: the
  site and link previews never see it, and the join page counts nothing. The link holds no secret, and nothing changes
  on a teammate's Mac until they connect with a code from their own Slack account.
- A link that opens Pacenote on a hub now says it came from a link to the team hub, as the installer's is not the only
  one.

## pacenote.dev

- **Guide.** From install to Pace's first answer, joining your team's hub, Todo and Settings > Messengers, in English and
  Korean, with the app's own screens.
- **News.** New features and release notes in one place, with an RSS feed. Release notes are written in Korean too from
  this one.
