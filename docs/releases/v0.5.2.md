Pacenote has one sandbox now, the one built in: the Docker sandbox is gone, and diagrams render in a VM of their own.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first and reopens it, once. Config and run history are untouched.

## Before you upgrade

- **With the Docker sandbox**, the app switches the setting to the built-in sandbox when it opens. Run "Set up built-in
  sandbox" in Settings > Sandbox once: the first time it downloads a Linux kernel of about 290 MB, then builds the images
  in a few minutes. Pace answers again once it is set up. Your claude token, allowed domains and ops tool settings carry
  over.
- **Diagrams** need that setup too, even with answers running on this Mac.
- **On an Intel Mac or macOS 14 and earlier**, the built-in sandbox cannot run, so answers run on this Mac, and ops tools
  and diagrams are not available there.

## The built-in sandbox, alone

- Settings > Sandbox > Run environment offers On this Mac or the built-in sandbox, a Linux VM per request with nothing
  else to install (Apple silicon, macOS 15 or later).
- "Set up built-in sandbox" also builds the diagram renderer's image when diagrams are on, and the broker's when ops tools
  are on. Settings shows each image beside the reasoner's.
- The ops broker runs only in its own VM. It prepares its files as it starts, so its settings apply when Pace restarts,
  and there is no Recreate broker any more.
- `SANDBOX_IMAGE`, `SANDBOX_NETWORK`, `SANDBOX_PROXY_URL`, `OPS_BROKER_URL`, `RENDERER_IMAGE` and `DOCKER_BIN` are no
  longer read. They stay in `.env`, listed as other entries.

## Diagrams

- Diagrams and charts render in a VM with no way out at all, which sees only the folder with the block and its PNG.
  Generated images are shrunk there too.

## The old Docker sandbox

Nothing uses its containers, network and images any more, but the proxy and broker containers restart with Docker until
removed:

```sh
docker rm -f pacenote-sandbox-egress-proxy-1 pacenote-sandbox-ops-broker-1
docker network rm pacenote-sandbox pacenote-egress
docker volume rm pacenote-sandbox_ops-work
docker image rm pacenote-reasoner pacenote-renderer pacenote-egress-proxy pacenote-ops-broker
```

See [Reasoner sandbox](../sandbox.md#before-the-built-in-sandbox).
