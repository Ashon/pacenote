A session keeps one conversation wherever you type into it: send from Pacenote to one resting in the Claude app or a
terminal, and it continues here, in the same session, not a copy.

```sh
brew update && brew upgrade --cask pacenote
```

## One conversation, continued where you type last

- A Claude Code session resting in the Claude app or a terminal now has the composer on its page. What you send ends
  its process there and resumes the same session here, so its next turn knows everything said in both places.
- Back in the Claude app, type as before: the app resumes the session again, with what was said in Pacenote. A
  terminal's Claude Code closes when the session moves here; `claude --resume` opens it there again.
- A session working in the Claude app or a terminal is shown as it goes, and you continue it here once its turn is
  done. **Continue in a copy here** is still there when you want a separate copy.
- A session Pacenote runs, opened somewhere else afterwards, is let go while it rests, so you type there. If it was
  continued somewhere else while Pacenote rested, Pacenote picks it up again from its log before your next message
  goes to it, asking before it acts as you had it.
- Sessions on claude.ai (Remote Control) stay where they run: watch them here, or continue in a copy.
