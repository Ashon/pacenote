The Tasks screen now collects with one button.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## Collect now

- **Collect now** on the Tasks screen reads Slack and adds your tasks, in a minute or two. While it runs, the screen shows
  how far it got, and Stop ends it; afterwards, what it added, or why it could not collect.
- It runs Claude Code in the background, with the Slack connector of your claude.ai account, kept to the collection: only
  Slack's read tools and Pacenote's task tools are allowed, and sending, drafting, scheduling, reacting and canvases are
  denied. Your own Claude Code settings, plugins, CLAUDE.md and MCP servers are not loaded, so a collection starts small
  and quick.
- Claude Code does not need Pacenote added for this. Adding it in Settings > Tasks is for asking Claude Code or Codex about
  your tasks, or collecting from inside them.
- The setting is now called **Gather my tasks from Slack**.

What it needs: Claude Code on this Mac, signed in, with Slack connected in claude.ai's Settings > Connectors.
[Your tasks from Slack](../tasks.md) has the details.
