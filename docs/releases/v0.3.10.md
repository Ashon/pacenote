The status bar now says which Pacenote you are running.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## The version in the status bar

- The right end of the status bar shows the version, such as `v0.3.10`. Clicking it opens that version's release notes.
- A build from the repository (`pnpm desktop`) shows where it stands in git instead, such as `v0.3.10-2-g1a2b3c4-dirty`:
  two commits after v0.3.10, with uncommitted changes. The tooltip spells it out.
