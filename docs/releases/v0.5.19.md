Todo can say when a task looks done once its session goes quiet, and work a session leaves after a task, or something
you ask your AI tool to keep for later, becomes a task of your own.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first and reopens it, once. Claude Code and Codex sessions already open keep the
previous Pacenote tools until they start again.

## When a task looks done

Turn on Settings > Todo > "Say when a task looks done"; it is off until you do.

- **After the session goes quiet.** When the latest session of an open task has been quiet for 10 minutes, Claude Code
  reads its last turns and the state of its branch's pull request, and says whether the work is done, how it ended and
  what is left.
- **Kept to reading.** It runs headless with no tools, no MCP servers and none of your Claude Code settings, on your
  Claude Code login. The pull request is looked up with `gh`, read only.
- **Yours to close.** A task that looks done says so on its row. Open it for **Close it** (closed as done in its
  session, with how it ended as its wrap-up) or **Not yet**, and **Keep as a task** beside each thing left.
- **Not over and over.** A session is read again only after it was active again, at most two at a time, while Todo is
  open.

## Tasks a session keeps

- **`add_followup`.** Work left after a task, or "remember to bump the SDK after the release", becomes a task with the
  source **This Mac**, in the repository of the task it follows or the session's folder. `/mcp__pacenote__done` keeps
  what is left after the work it closes this way; work that is not done is kept only if you want it kept.
- **Where it came from.** Its row says which task it was left after. It has no Slack thread, so collections leave it
  alone and there is no reply to draft; the session that does it, or you, closes it.
- **Once.** The same title left after the same task, still open, is kept once.

The app and each session's Pacenote tools now take turns writing your tasks, so one no longer overwrites what another
just changed.
