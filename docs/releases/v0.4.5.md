The Tasks screen's collections line up as they should.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## Fixes

- **Recent collections** keeps each part in its own column: when, how it started, what it found and its tokens, so the
  rows line up. Days read Today, Yesterday or the weekday.
- What the last **Collect now** added, the new tokens it spent and its Slack lookups stay on the Tasks screen after the
  app restarts.
