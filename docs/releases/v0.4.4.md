Pacenote now shows what its work takes in tokens: answering your mentions, and collecting your tasks.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## Tokens

- The Overview has a new band: **Tokens per day** over the last 14 days, mentions at the bottom of each bar and task
  collections on top, beside **By source**, with each one's total, per run or per collection, and per task found.
- Tokens are counted in four parts: new input, cache read, cache write (claude only) and output. The Overview tracks new
  tokens, everything but cache reads; cache reads are most of the input and cost far less, so they show apart.
- A run's **Tokens** figure shows its new tokens and what came from the cache, and breaks down into the four parts on
  hover. With claude, the hover also gives the cost at API prices.
- Runs from earlier versions show the same way. codex counted the cached input as input, and those runs are read with
  it apart; earlier claude runs have no cache writes recorded.

## Collections

- When **Collect now** finishes, the Tasks screen says what it added, the new tokens it spent and how many Slack lookups
  it made.
- **Recent collections** under the list shows the last 7 days of collections: when, how each ended, and its tokens. The
  app keeps them for 90 days in `tasks-collections.json` in the data folder.
- Only the collections Pacenote runs count: one run from inside your own AI tool spends that tool's tokens.

## Other

- The open task count beside Tasks in the sidebar is a badge now, and shows on the icon in the compact sidebar.
- The Overview's bars stay round at both ends, a failure on top of a short day too.
