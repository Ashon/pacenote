The claude token you set by hand gives way to signing in.

```sh
brew update && brew upgrade --cask pacenote
```

## Sandbox sign-in

- **Signed in, the token goes.** Once Claude is signed in inside the sandbox, Pace uses that sign-in, so a claude token
  you set by hand (`sandbox.claudeToken`) goes unused. Pacenote now removes it from your settings, and from the old
  `.env.bak`, when you sign in and whenever it starts, so it keeps no claude.ai token it does not use.
- **Still on the token?** Settings > Sandbox says it is going away: sign in to Claude there, and the token is removed.
  A later release stops reading it.
- **No new tokens.** The claude token row under Advanced shows only while a token is there. An Anthropic API key works
  as before.

## Upgrading

- Upgrading from 0.6.8, the first version that goes at once when Homebrew's quit request opens it again, Homebrew
  reopens Pacenote on its own once the upgrade is done.
