A screen that does not load no longer ends Pacenote.

```sh
brew update && brew upgrade --cask pacenote
```

## Starting and restarting

- **No more "Pacenote could not start".** When the window cannot load its screen, whether an upgrade is swapping the
  app's files as it opens or anything else, Pacenote no longer shows an error and quits. The window tries again on its
  own and, when that takes more than a moment, says why in its place with "Try again". Pace and the menu bar keep
  running meanwhile.
- **Opening it again while it quits.** Opened right after Quit, while Pace finishes a request, Pacenote opens again once
  it has quit instead of going away.
- The old version is the one running during an upgrade, so the upgrade to this version can still show the error once.
  Upgrades after it do not.
