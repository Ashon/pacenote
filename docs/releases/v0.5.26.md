The sandbox signs in to Claude Code or Codex on its own, inside it, and Pacenote never handles the login. Answers say an
AI wrote them, and what Pace says in a channel leaves out your private channels.

```sh
brew update && brew upgrade --cask pacenote
```

**Codex in the sandbox: sign in once after upgrading.** The sandbox no longer copies this Mac's `~/.codex/auth.json`.
Until you sign in, Pace starts and the status bar says so: Settings > Sandbox > Reasoner login > **Sign in to Codex**.
Claude keeps working with the token you have; signing in to Claude there replaces it.

## The sandbox signs in on its own

- **Sign in to Claude or Codex inside the sandbox.** Settings > Sandbox > Reasoner login, and setup's sandbox step, run
  the CLI's own login in a VM: Claude shows its page, and you paste the code it gives back into Pacenote; Codex shows a
  code to enter on OpenAI's page. The CLI keeps its login in a folder of its own (`~/.pacenote/vm/login`), renews it
  there itself, and each request's VM has it. Pacenote never reads it: it checks only that the login is there.
- **No more tokens through Pacenote.** "Get token from Claude", which saved `claude setup-token`'s output to your
  settings, is gone, and so is copying this Mac's codex login into each VM. A login the sandbox renewed could undo this
  Mac's codex login; that no longer happens. An Anthropic API key, or a claude token you set yourself, still works.
- **Pacenote never calls Anthropic's API with a claude.ai token.** Only an API key is checked that way now; a claude.ai
  login that stopped working shows when a request fails on it.
- **Its sign-in domain is always allowed.** Claude renews its login at `platform.claude.com`, which requests reach
  whatever your allowed-domains list says.

## What Pace says in a channel

- **Your private channels stay out.** Asked in a public channel, Pace's tools gave your tasks from DMs no hearing but
  could still name tasks, areas and recaps from your private channels. Now they speak only of public channels and your
  own work on this Mac. A channel Slack cannot tell about counts as private, and the recap you wrote is left out, since
  it was written from all of it.
- **Every answer says an AI wrote it.** A line under each answer reads "AI answer by Pace, with Claude Code" (or Codex):
  everyone in the channel reads the answer, not only you. The run history keeps the answer without it.
