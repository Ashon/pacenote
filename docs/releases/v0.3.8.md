A fix for "Get token from Claude": the token it saved could be cut short, and Pace then failed every request.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## If Pace answers "I couldn't produce an answer"

Settings > Sandbox > Reasoner login > "Get token from Claude" (or "Get new token") runs `claude setup-token` and saves the
token it prints. Claude Code prints the token over two lines, and the app kept only the first one, so the saved token
was cut short: requests then failed with `401 OAuth access token is invalid` in the run history.

The app now joins the lines, and saves the token only once all of it has arrived. If a run of yours failed that way,
upgrade, choose "Get new token" once more, approve in the browser, and restart Pace.
