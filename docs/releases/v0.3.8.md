**Use v0.3.9 or later instead.** This release meant to fix "Get token from Claude", but it guessed the cause wrong: with
it, the button saves no token and ends with "claude setup-token ended without a token".

```sh
brew update && brew upgrade --cask pacenote
```

## What went wrong

Settings > Sandbox > Reasoner login > "Get token from Claude" (or "Get new token") runs `claude setup-token` and saves the
token it prints. Earlier versions saved the token with a few extra letters stuck to its end, and every request then
failed with `401 OAuth access token is invalid`.

This release took that for the token being wrapped over two lines, and waited for a blank line after it. The real cause
is that Claude Code redraws its screen by rewriting only the characters that changed, so read as a stream the token runs
into letters of the next line, and the blank line never comes as such. v0.3.9 reads the screen as a terminal draws it;
see its release notes.
