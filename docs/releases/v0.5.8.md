Finished tasks now say how they ended, so the next task like them starts with what happened last time. Code tasks open in
the terminal you use, and continuing a session from a task is easier to spot.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first and reopens it, once. Config, run history and your tasks are untouched.

## After you upgrade

- Restart Claude Code or Codex sessions you have open, so they get Pacenote's new `wrap_up_task` tool.
- The first **Collect now** wraps up tasks you finished in the last 7 days, five at a time, so it reads a few more threads
  than usual.
- Code tasks now open in the terminal you use. If you chose Terminal or iTerm in Settings before, that choice stays; pick
  Automatic to switch.

## Todo

- **Finished tasks are wrapped up.** When a collection closes a task, or finds one you marked Done in the last week, it
  reads the thread and writes how it ended in two or three sentences: what was done or decided and by whom, and anything
  left. A finished task's open row shows it on its Result line. On a new task, hover the note on its Last time line to
  read how the earlier one ended. Dismissed tasks get none.
- **Continue a session from its line** with the terminal icon at the end of Last time and Your work, the same icon as the
  row's Continue button. Its name shows on hover and to screen readers.
- A collection's detail in Runs lists the tasks it wrapped up.

## Continuing work

- **Opens in the terminal you use.** Settings > Todo > Terminal is now Automatic by default: the terminal you have open,
  else the one you used last. You can also choose Terminal, iTerm2 or Ghostty.

## AI tools

- Pacenote's MCP server has a new tool, `wrap_up_task`, and `close_task` takes a `wrap_up`.
- `task_context`, and the first prompt of a session Pacenote opens, say how earlier tasks ended.
