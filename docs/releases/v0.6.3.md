Todo stays short however much you settle: Done lists ten at a time, and the collections have a tab of their own.

```sh
brew update && brew upgrade --cask pacenote
```

## Todo

- **Done lists ten at a time.** It shows the ten tasks you settled last, the latest first, and **Show more** adds ten
  more each time. A task opened from a link is listed however far down it is.
- **Collections have their own tab.** Recent collections no longer waits below a long list: the new **Collections** tab
  beside Open, Maybe and Done lists the last 7 days of collections, ten at a time, each still opening its run in Runs.
- How many of the tasks you settled you dismissed now sits above Done's list, as the note on Maybe does.
