A task in Todo opens in its own row instead of on a page of its own: a short reminder of what it is about and what came
before, with the list staying where it was.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first and reopens it, once. Config, run history and your tasks are untouched.

## Todo

- **A task opens in place.** Click its title: the row shows the thread summed up, how it ended once it is settled, and
  one line each for what came before: **Last time** (an earlier session to continue, Pace's answer in the thread, or
  the person's last task), **Your work** (your last Claude Code or Codex session) and the rest on request. The list keeps
  its tab and scroll, and only one task is open at a time.
- **One next step per row.** Continue in Claude Code for code, Draft a reply for replies, then Done and Dismiss as
  before. Continue in the other tool and Draft a reply for any task are under the row's `⋯` menu.
- **A session's log** opens in a panel over the list. Esc closes it.
- **A reply** is drafted, edited and copied in its row. Pacenote never sends it for you.
- A task closed from its session stays where it was, struck through, until you close its row, with the reply the
  session drafted for you to send.
- Up and down move between tasks, with the open one following. Esc closes it.
