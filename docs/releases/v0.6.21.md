A fix for Pace on Codex in the built-in sandbox: an answer whose MCP tool returns an image, such as a console screenshot,
no longer fails with "failed printing to stdout".

```sh
brew update && brew upgrade --cask pacenote
```

## Fixes

- With Codex in the built-in sandbox, an answer stopped with `pacenote-vm exited with code 101` once a tool returned a
  big result, such as an image from one of your MCP servers. The sandbox's ways out shared the answer's output and made
  it non-blocking, and Codex quit when the output filled up. Each answer now writes its output on its own, so the result
  reaches Codex and Pace answers.
- It works with the sandbox images you already have: there is nothing to set up again.
