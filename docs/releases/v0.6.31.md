A session's page shows what Claude Code does now, and reads like its conversation: answers in Markdown, steps by what
they did, and what Claude Code adds to your turns shown as meant.

```sh
brew update && brew upgrade --cask pacenote
```

## What it does now

- While a session Pacenote runs is on a turn, the end of its page says what it does and for how long: **Thinking**, the
  step it runs, or its answer as it writes it, word by word.
- A session open in a terminal or another app says it works there.

## Its conversation

- Answers show as **Markdown**: headings, lists, bold, code.
- Steps show by what they did (a command, a file read or changed, a search, a web page, an MCP tool), with paths from
  the session's folder. A step that failed is marked **Failed**. More than three in a row fold into one line, such as
  "4 steps · Read 2 · Grep · Bash", to open.
- What Claude Code adds to your turns shows as meant: a slash command and what it printed, a command run with `!` and
  its output, a background task's notice, a turn you stopped, images you sent. A long session's summary, from when
  Claude Code compacted it, shows folded.
- Claude Code's reminders to the model and its own lines are left out.
- A task's session log shows the same way.
