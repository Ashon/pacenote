A fix for the Mac window in full screen: closing it there no longer leaves a black screen behind.

```sh
brew update && brew upgrade --cask pacenote
```

## Fixes

- Closing Pacenote's window while it was in full screen hid the window but left its full-screen space on screen, all
  black. The window now leaves full screen first and hides once it has, as a Mac app's window does. Open it again from
  the Dock or the menu bar and it comes back in its own size.
